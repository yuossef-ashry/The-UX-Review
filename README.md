# 🎨 Neubrutalism UI — CSS Landing Page

A modern and visually distinctive webpage built using **HTML5 and CSS3** as part of my Front-End Development journey at **Route Academy**.

This assignment focuses on exploring the **Neubrutalism UI style**, a bold and trendy design approach characterized by strong borders, contrasting elements, bold typography, and prominent shadows.

The main goal was to apply the CSS concepts I learned in a practical project while recreating the provided design as accurately as possible.

---

## 📌 Project Overview

This project is a **Neubrutalism-style webpage** created to practice advanced CSS styling and understand how different visual properties can work together to create a unique user interface.

The design focuses on bold visual elements, strong borders, shadows, spacing, and typography to achieve the distinctive Neubrutalism aesthetic.

One of the most valuable lessons from this assignment was understanding how **small CSS properties can completely change the personality of a design**.
