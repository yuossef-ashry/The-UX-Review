## 📖 About The Project

**The UX Review** is a minimal yet visually compelling blog website focused on User Experience Design. Built with a design-first mindset, the site prioritizes clarity, readability, and seamless navigation — essentially practicing what it preaches.

The project serves as both a content platform and a showcase of front-end skills, demonstrating how good design principles translate directly into clean, well-structured code.

---

## 💡 Project Idea

The site is a blog that covers topics related to:

- 🎨 **UX Design** — principles, patterns, and best practices
- 🔍 **UI Analysis** — breakdowns and critiques of real-world interfaces
- 📝 **Articles & Tips** — actionable advice for designers and developers
- 🧪 **UX Reviews** — honest evaluations of digital products and experiences

---

## 🎯 Goals

- Deliver a **clean, distraction-free reading experience**
- Present content in an **organized and visually scannable** layout
- Demonstrate strong proficiency in **HTML5 & CSS3**
- Build a **fully responsive** interface that works beautifully on all screen sizes
- Keep the design **minimal without being boring**

## 📐 Design Philosophy

> *"Good design is as little design as possible."* — Dieter Rams

The UX Review is built on three core principles:

1. **Clarity** — Every element has a purpose; nothing is decorative without reason
2. **Consistency** — Uniform spacing, typography, and color usage throughout
3. **Accessibility** — Readable fonts, sufficient contrast, and logical content flow
